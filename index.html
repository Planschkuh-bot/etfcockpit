ETFCockpit

Import

Lade den CSV-Export aus Dipsy (Semikolon-getrennt, Spalten Symbol, Name, Kaufpreis, Stueckzahl, Kaufdatum, Art). Die Daten bleiben in deinem Browser.

Alternativ: CSV-Text einfügen

Transaktion manuell erfassen

Ergänzt einen Kauf oder Verkauf direkt im Depotbuch, zum Beispiel für Positionen, die nicht in der CSV stehen.

Depotbuch laden

Lädt ein zuvor gespeichertes Depotbuch (Transaktionen, Ticker, Einstellungen, Kurse). Die Daten auf diesem Gerät werden dabei ersetzt.

Export

Speichert alle Daten (Transaktionen, Ticker, Einstellungen, Kurse) als Depotbuch-Datei, z. B. um sie vom PC aufs Handy zu übertragen.
Alle Daten bleiben lokal im Browser. Die Auswertungen sind Schätzungen, maßgeblich sind die Steuerdaten deines Brokers.
